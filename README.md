- **[People's Budget Portal](https://budget.naga.gov.ph)**: frontend for Naga City's open-source participatory budgeting platform, built with Stride Technologies and led by WeSolve Foundation.
- **[LGU Health Spending Lens](https://nuque.dev/lab/lgu-health-lens/overview)**: joins PIDS health spending with DBM COMPASS data into one brief per LGU, with open data and a read-only API.
